# Color Rush — RGB Scoreboard

Live scoreboard for a physical color-matching game built with Arduino Uno + ESP8266.

Players match a randomly generated RGB color using a rotary encoder. The deviation between the target and their guess is sent to Supabase via Wi-Fi and displayed here.

🌐 **Live site:** [yousuf-m03.github.io/IoT-RGB](https://yousuf-m03.github.io/IoT-RGB/)

Built for DTU Electro 34315 IoT course — Group M03.
